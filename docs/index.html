解決的問題

01

素材太多，找不到那顆鏡頭

以自然語言檢索，支援中、日、英 —— 比對的是畫面內容與逐字稿，而非檔名。

02

多數 AI 剪輯工具僅能處理有對白的素材

arkiv 對每一支素材同時執行視覺分析與語音轉錄，因此 B-roll 與無對白空景同樣可檢索、可管理。

03

素材庫要能餵給下游任何剪法

無論手動剪輯、自動化流程或腳本驅動皆可銜接：Resolve 原生外掛、EDL / FCPXML 匯出、REST API 與 MCP 介面。

系統需求與注意事項

01安裝檔已內含 Python 後端與 ML 套件，惟仍需自行安裝 FFmpeg 與 Ollama，供抽幀、向量運算與視覺分析使用。
02macOS 版僅支援 Apple Silicon，未提供 Intel 版本。
03安裝檔尚未經數位簽章。macOS 首次開啟請使用「右鍵 → 打開」，Windows 會顯示一次 SmartScreen 提示，後續開啟不再出現。
04視覺分析仰賴 GPU 加速。無獨立顯示卡亦可運作，處理時間將顯著增加。
