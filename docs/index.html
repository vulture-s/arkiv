它解決什麼

01

素材太多，找不到那顆鏡頭

用自然語言搜，中日英都行 —— 搜的是畫面內容和逐字稿，不是檔名。

02

AI 剪輯工具只看得懂「有人在講話」的素材

arkiv 對每支 clip 做視覺分析 加 轉錄，所以大量 B-roll、無對白空景一樣可搜可管。

03

素材庫要能餵給下游任何剪法

手動剪、自動剪、腳本剪都接得上：Resolve 原生 plugin、EDL / FCPXML 匯出、REST API 與 MCP 介面。

不是 demo 專案

1,506 支

真實產品拍攝素材完整索引跑通，其中 1,161 支是無對白 B-roll —— 也就是一般字幕工具完全抓不到的那些。單張 RTX 4070，5,732 幀視覺描述，零缺口。

安裝前先知道

01安裝檔包含 Python 後端與 ML 套件，但你仍需自行安裝 FFmpeg 與 Ollama（抽幀、向量、視覺分析要用）。
02macOS 版僅支援 Apple Silicon，沒有 Intel build。
03安裝檔未經簽章。macOS 首次要「右鍵 → 打開」，Windows 會跳一次 SmartScreen 警告。這是刻意的：簽章憑證每年要錢，那筆錢目前寧可不花。
04視覺分析吃 GPU。沒有獨顯也跑得動，但會慢很多。
